# UniNotebook dependencies
#
# No external services required: SQLite + embedded ChromaDB + in-process background tasks.
#
#     pip install -r requirements.txt
#     python run.py
#
# Lower bounds reflect the versions this was actually tested against. They're `>=` rather than
# `==` because exact pins tend to collide with whatever else is in your environment; if you
# need a fully reproducible install, generate a lock file with `pip freeze`.
#
# Heavier features (paper-to-slides, posters, audio overviews) need extra packages and API
# keys and are not installed by default. Missing them doesn't break anything — the UI just
# greys out those entry points. See the bottom of this file to add them.
